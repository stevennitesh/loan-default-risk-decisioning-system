The files retain their original bytes and numbers. Their embedded labels need
qualification: dollar-formatted values are illustrative utility units, held-out
wording describes a reused historical comparison population, and production-like
scoring describes an unlabeled demonstration. These are not measured profit,
independent final-test evidence or production deployment.

The PBIX files contain embedded data models with score-table bindings. Their
cached rows, DAX measures, relationships and import settings have not been
verified through native Power BI inspection. Archiving does not certify those
contents as aggregate-only.

A future refresh must reconcile every visual to one identified export bundle.
See the [Power BI guide](../README.md) for schemas, commands and inspection limits.
